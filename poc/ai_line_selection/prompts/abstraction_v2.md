# abstraction / abstraction-only-v2

入力は合成された日記または既存Lineのどちらかです。どちらにも同じ規則を使い、Embedding検索専用の短い関係概念を1つだけ抽出してください。

- 表層的な主題名ではなく、入力に含まれる関係、変化、両立、緊張、ずれ、留保、反復などの構造を表す。
- 日本語の簡潔な名詞句にし、目安を8〜30文字、上限を60文字とする。
- 入力が日記かLineかを出力へ書かない。
- 原文の数量、人物、物、場所、時刻、固有名詞、個別の出来事を不要に複製しない。
- 原文にない数量、人物、物、出来事、因果、意図、感情、評価を追加しない。
- 診断、助言、励まし、称賛、感情や人物像の固定をしない。
- 「一人」「誰にも会わない」「静けさ」「未共有」は、それだけで「孤独」「寂しさ」「孤立」を意味しない。原文にその感情・状態が明示されない限り、単独、静けさ、未共有など観察できる関係のまま表す。
- 小さな出来事を肯定的に見ていることは、それだけで「達成」「成功」を意味しない。目標の完了が明示されない限り、意味の増加、充足感、評価の変化など原文にある関係だけを表す。
- 比喩は具体物を反復せず、比喩が表す関係だけを抽象化する。
- themes、structure、説明、候補、Markdownを出力しない。
- 指定されたJSON Schemaだけを返す。
